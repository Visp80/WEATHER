# WEATHER

Простий Python-скрипт для отримання погоди в реальному часі з Open-Meteo API. Скрипт показує поточну температуру, вітер, вологість, опади, погодинний і денний прогноз, а також попереджує про небезпечні погодні умови.

## Короткий опис

`weather.py` отримує дані про погоду за координатами з файлу `config.json`, відображає їх у консолі та, за бажанням, надсилає Telegram-репорт. Скрипт також зберігає кеш погодних даних і історію за останні 30 днів.

## Принцип роботи

1. Скрипт читає конфігурацію з `config.json`.
2. Визначає координати місця або використовує значення за замовчуванням.
3. Надсилає запит до Open-Meteo API.
4. Парсить відповіді: поточну погоду, погодинний прогноз і денний прогноз.
5. Відбирає найважливіші показники: температуру, вологість, вітер, опади, код погоди.
6. Генерує рекомендації для користувача (одяг, безпека, можливі ризики).
7. Перевіряє небезпечні погодні умови: сильний вітер, дощ, сніг, грози, туман тощо.
8. Виводить результат у консоль.
9. За потреби надсилає повідомлення в Telegram.
10. Зберігає кеш і історію погоди для подальшого використання або офлайн-відновлення.

## Запуск

```bash
pip install -r requirements.txt
python weather.py
```

## Додаткові параметри

```bash
python weather.py --help
```

Основні аргументи:

- `--city <назва>` — змінити місто без збереження в конфіг
- `--no-notify` — вимкнути Telegram для поточного запуску
- `--no-hourly` — не показувати погодинний прогноз
- `--no-daily` — не показувати денний прогноз
- `--quiet` — мінімал��ний вивід в консоль
- `--json` — вивести результат у форматі JSON
- `--no-cache` — не використовувати кеш при помилці
- `--config <path>` — вказати інший файл конфігурації

## Примітка

Якщо API недоступне, скрипт намагатиметься використати збережений кеш, що дозволяє продовжити роботу без інтернету.
